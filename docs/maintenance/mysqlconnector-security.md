# MySqlConnector security update — 1 November 2026

## Change and scope

[GHSA-473q-m89c-ghf8](https://github.com/advisories/GHSA-473q-m89c-ghf8) affects MySqlConnector versions below 2.6.1. With VerifyCA/VerifyFull, no configured SslCa and a nonempty password, a malicious remote server/proxy can obtain a clear-text password before certificate verification. The advisory excludes local/loopback connections. This report does not establish exposure or compromise of an installed system.

The Windows launcher previously directly referenced 2.5.0. The Web app resolved 2.4.0 through Pomelo.EntityFrameworkCore.MySql 9.0.0. Both now explicitly reference 2.6.1, the first patched version. Pomelo's published dependency range permits MySqlConnector >= 2.4.0; no EF Core/provider upgrade is required. See the [upstream release](https://github.com/mysql-net/MySqlConnector/releases/tag/2.6.1) and [provider dependencies](https://www.nuget.org/packages/Pomelo.EntityFrameworkCore.MySql/9.0.0).

The Web lock file is generated by restore, retaining net8.0 and net8.0/linux-arm64. The launcher has no tracked lock file. Existing connection settings, TLS validation, database schema/baseline/history and packaging procedures are unchanged. The existing MySqlConnector MIT notices remain applicable. C01–C20 remain closed; this is subsequent security maintenance.

## Validation

- Solution restore and Linux ARM64 Web restore passed with MySqlConnector 2.6.1.
- Release solution build passed with zero warnings/errors (Web and Windows launcher).
- 14 development startup configuration checks passed.
- 24 Desktop migration policy scenarios passed; 248 packaged migrations validated.
- NuGet vulnerability audit with indirect dependencies reported no vulnerable packages in Web, launcher or RichNotes.Checks using api.nuget.org.
- Existing isolated database/HTTP regression suite passed all 186 tests in 12 groups against upgraded and schema-only fresh fixtures, plus 12 export-preflight policy checks. This covers database access, closure, ended-plant validation, validation messages, transactions/concurrency, photos and history ordering. Generated test databases were cleaned up; no collection database or tracked schema was changed. Python 3.14 emitted HTTPError cleanup ResourceWarnings during expected rejection cases; all tests passed.

These checks do not reproduce the upstream man-in-the-middle exploit or establish installed Pi/Windows release acceptance. GitHub CI and real installed acceptance for this revision remain pending.

## Adoption

Rebuild and distribute the complete Web application and Windows launcher through the normal release process; updating source alone does not patch installed binaries. Verify MySqlConnector 2.6.1 in both resolved dependency graphs and rebuilt payloads, then check startup, database-backed save/reopen and readiness on the target machine. Linux uses the rebuilt Web payload. Windows needs both rebuilt Web and launcher payloads. Keep the normal paired backup and application/configuration recovery procedure. No SQL migration, database recreation or new configuration is required. Do not suppress the advisory or weaken TLS settings to remove the warning. Retained old binaries/rollback packages remain affected and are not patched by this source change.
